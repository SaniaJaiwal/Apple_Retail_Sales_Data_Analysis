# Apple Retail Sales Data Analysis using SQL


## Project Overview

This project focuses on analyzing an Apple Retail Sales dataset containing over 1 million records using PostgreSQL. The dataset includes information about Apple products, retail stores, sales transactions, and warranty claims across various locations worldwide. 

The project follows an end-to-end data analysis workflow, starting with database and table creation, followed by data import, exploratory data analysis (EDA), query performance optimization, and business-focused SQL analysis. The analysis uses both basic and advanced SQL queries to uncover patterns in sales, product performance, store performance, warranty claims, and product sales trends over time.

## Apple Retail Sales Dataset

The dataset contains over 1 million rows of Apple retail sales data and represents real-world business scenarios involving:

- **Stores**: Contains information about Apple retail stores.
- **Category**: Holds product category information.
- **Products**: Details about Apple products.
- **Sales**: Stores sales transactions.
- **Warranty**: Contains information about warranty claims.

The dataset includes multiple product categories and retail locations, making it suitable for exploring sales performance, customer service activity, and business trends.

**The complete dataset is available here**: **[Dataset](https://www.kaggle.com/datasets/amangarg08/apple-retail-sales-dataset/data)**

## Key Areas of Analysis

The project explores several important business areas:

- **Sales Performance**: Analyzed sales volume, monthly sales, store-level performance, product performance, and sales trends over time.
- **Store Performance**: Compared stores based on total units sold, yearly growth, and best-performing sales days.
- **Product Analysis**: Analyzed product popularity, category-level pricing, product performance, and sales behavior at different stages of a product's lifecycle.
- **Warranty Analysis**: Examined warranty claim frequency, rejected claims, claims occurring shortly after purchases, and warranty activity across countries, stores, and product categories.
- **Time-Based Analysis**: Used date-based analysis to identify seasonal trends, monthly performance, year-over-year growth, and product sales patterns based on time since launch.

## Conclusion

This project demonstrates end-to-end data analysis using SQL, applying EDA, query optimization, and advanced SQL techniques to analyze sales, store performance, product trends, and warranty activity.
